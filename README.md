# Instagram Reels — «چطور یک اکانت دوم اینستاگرام بسازیم؟»

A ready-to-render 30-second vertical Instagram Reel, built with **Remotion**
(React → headless Chrome → ffmpeg). Persian copy, real RTL shaping, motion
graphics, music, SFX and a Persian AI voice-over — all generated by code in
this repo, no stock footage or placeholder media.

**Output:** `out/reel-second-account.mp4` — 1080×1920 · 30.00 s · 30 fps · H.264 + AAC

## Quick start

```bash
npm install
sh scripts/render.sh          # rebuild audio + render the MP4 + run QC
```

Or step by step:

```bash
python3 scripts/make_music.py   # 30s music bed, 120 BPM
python3 scripts/make_sfx.py     # tap / click / pop / whoosh / swipe / transition / success
python3 scripts/make_voice.py   # Persian narration, one clip per scene
npx remotion render src/index.ts Reel out/reel-second-account.mp4 --crf=18 --pixel-format=yuv420p
node scripts/verify_output.mjs  # QC: duration / resolution / fps / codecs
```

Scrub the timeline interactively:

```bash
npm run studio
```

## Timeline (exactly 900 frames @ 30 fps = 30.00 s)

| scene           | visible   | content                                      |
| --------------- | --------- | -------------------------------------------- |
| `Scene1Hook`    | 0–3 s     | «می‌خوای یه اکانت دوم اینستاگرام داشته باشی؟ 👀» + glowing Profile tab |
| `Scene2Intro`   | 3–7 s     | «لازم نیست از اکانت فعلیت خارج بشی!» + arrow to Profile |
| `Scene3Profile` | 7–12 s    | ۱. برو روی پروفایل — pointer taps the Profile tab |
| `Scene4Username`| 12–17 s   | ۲. روی نام کاربری بزن — username highlight + compact menu |
| `Scene5AddAccount`| 17–22 s | ۳. Add account رو بزن — action sheet, «ساخت حساب جدید» highlighted |
| `Scene6Form`    | 22–27 s   | ۴. اطلاعات اکانت جدیدتو وارد کن — username / password / email |
| `Scene7Outro`   | 27–30 s   | «تموم شد! 🎉» + «حالا دو اکانت روی یه گوشی داری.» + CTA |

Cuts fall on **3 / 7 / 12 / 17 / 22 / 27 s**; transitions are 10 frames (0.33 s).
`src/utils/timeline.ts` derives the per-scene durations from those cut points —
with `TransitionSeries` a sequence starts at `start(i-1) + duration(i-1) - 10`,
so the durations are solved backwards from the required cuts.

## Persian / RTL notes

* Arabic/Persian shaping is done by the browser engine, so nothing is ever
  rendered letter-by-letter — copy is passed through as whole strings and never
  split per character.
* `src/utils/rtl.ts` provides the shared text style (`direction: rtl`,
  `unicode-bidi: plaintext`) and a Latin→Persian digit helper.
* Vazirmatn is loaded from `public/fonts` and blocks the first frame via
  `delayRender`, so text never renders in a fallback face.
* Instagram chrome is mirrored for RTL (avatar right, back chevron pointing
  right, story progress bar filling right-to-left).

## Verification

Because the render box has no display, layout is verified numerically:

* `scripts/verify_output.mjs` — duration / resolution / fps / codecs / range
* `scripts/measure_text.py` — prints the bounding box of every bright text line
* `scripts/ascii_preview.py` — renders a frame as ASCII art
* `scripts/qc_stills.py` — per-band ink coverage sanity check
